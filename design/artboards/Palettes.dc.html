Two exceptions — the only places mode does not govern appearance
EXCEPTION 1
SOS chrome is always urgent
Every screen on the rescue path — press-and-hold, context, status, rescue card — is drawn in identical urgent chrome in all three modes. It does not follow the theme and does not dim in Survival.
Rescue is not a theme. A person calling for help must recognise these screens instantly, with no “which mode am I in?” ambiguity at the worst possible moment. Mode still governs radios and background activity — only appearance is held constant.
PRD §5.5
EXCEPTION 2
Rescue card stays white
White surface, black text, maximum brightness in every mode including Survival. The only screen in Survival Mode that raises brightness rather than lowering it.
Its purpose is not to be read by its owner but seen by someone else — a rescuer at a window, a boat crew across a flooded street. A black screen cannot do that. Shown on demand, never left open by default.
The battery cost is stated to the user on the card itself.
